# AI-Based-Road-Pothole-Detection

AI-Based Road Pothole Detection and Automated Complaint Management System.

This project detects road potholes using AI, identifies their GPS location and severity, finds the responsible road authority, and generates complaints for road maintenance. Users can track complaint status, while officers can manage and update reported road issues.

## Technologies

- Java
- Spring Boot
- HTML
- CSS
- JavaScript
- MySQL
- AI/Computer Vision

## How to Use

1. Upload or capture an image of a road.
2. Allow location access to obtain the GPS location.
3. The AI model detects potholes in the image.
4. The system identifies the pothole severity and location.
5. The responsible road authority is identified.
6. A complaint is automatically generated.
7. Submit the complaint and receive a complaint ID.
8. Track the complaint status through the system.
